Rename photos with the date plus a description on a Mac

For a batch from one day, Finder's Rename turns IMG_ into 260921_walnut-lamp_ in one go. For each photo's own date and description, use a Shortcuts quick action or BetterAirdrop, free and on your Mac.

Finder: one date and description for a batch

  1. Select the photos from one day or one event.
  2. Control-click one, choose Rename.
  3. Choose Replace Text. Find: IMG_. Replace with: 260921_walnut-lamp_.
  4. Click Rename.
IMG_4821.HEIC → 260921_walnut-lamp_4821.HEIC

The number stays, so names don't clash. Add Text puts text before or after the current name instead.

Every selected photo gets the same words. Mixed days need one pass per day.

Source: Rename files, folders, and disks on Mac

Shortcuts: a description per photo

Yes, if you build it. Needs macOS 26 or later with Apple Intelligence (a Mac with M1 or later).

  1. New shortcut → Details → Use as Quick Action.
  2. Add Format Date, choose Custom, Format String yyMMdd.
  3. Add Use Model, choose On-Device. Prompt: “Describe this photo in 3 to 5 words for a filename.”
  4. Add an action that renames the file to the date, an underscore and the reply.
  5. Turn it on: System Settings → Privacy & Security → Extensions → Finder.
  6. Control-click photos → Quick Actions → your shortcut.

Format Date writes whichever date you give it. Picking the right one, and name clashes, are yours to handle.

Sources: Custom date formats in Shortcuts on Mac · Use Apple Intelligence in Shortcuts on Mac · Run a shortcut while working on your Mac · How to get Apple Intelligence

Or BetterAirdrop

  • Date and city from the photo itself
  • Description from Apple Vision, on your Mac
  • Runs on every AirDrop, or on photos you pick
  • Undo anything
IMG_4821.HEIC → 2026-09-21_toronto_walnut-lamp-on-oak-sideboard.jpg

Just date and description: set Settings → Naming → Name format to {date}_{subject}.

Compact date: date_format = "yyyymmdd" in ~/.config/betterairdrop/config.toml gives 20260921. There's no two-digit year.

$ betterairdrop rename --dry-run --template "{date}_{subject}" ~/Pictures/IMG_*.HEIC

Vision's descriptions are short, like tags. For fuller ones, add your own Claude API key.

Pro's name builder sets the parts, order, separator and date format with clicks.
