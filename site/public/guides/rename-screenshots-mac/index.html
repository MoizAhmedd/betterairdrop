Rename screenshots automatically on a Mac

macOS names every screenshot by date and time, never by what's on screen. Finder can't read them, but a Shortcuts quick action or BetterAirdrop can, free and on your Mac.

How macOS names them

  • Names start with Screenshot, then the date and time.
  • Shift-Command-3, -4 and -5 save to the desktop by default.
  • Shift-Command-5 → Options → Save to picks another folder.

A folder of their own keeps the desktop clear. It doesn't tell you which one is the invoice.

Sources: How to take a screenshot on your Mac · Take screenshots or screen recordings on Mac

Can Finder do it?

Select the screenshots, Control-click, choose Rename. Replace text, add text, or a name plus a number or date.

Good for swapping Screenshot for a project name. Every file still gets the same words.

Source: Rename files, folders, and disks on Mac

Can Shortcuts do it?

Yes, if you build it. Needs macOS 26 or later with Apple Intelligence (a Mac with M1 or later).

  1. New shortcut → Details → Use as Quick Action.
  2. Add Use Model, choose On-Device. Prompt: “Name this screenshot in 3 to 5 words for a filename.”
  3. Add an action that renames the file to the reply.
  4. Turn it on: System Settings → Privacy & Security → Extensions → Finder.
  5. Control-click screenshots → Quick Actions → your shortcut.

You run it on the files you select. Name clashes are yours to handle.
