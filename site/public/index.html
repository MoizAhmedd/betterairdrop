    How it works

    A name built from context, not guesswork.

    The date, the city, the kind of image and any text in it are worked out on your Mac. A short description of what's in the photo goes on the end.

    2026-03-29_copenhagen_croissant-ceramic-plate-wooden.jpg
    Capture dateFrom the photo's metadata, so names sort in the order you took them.
    City, or kindFrom a bundled offline city table. Screenshots, receipts and documents get their kind instead.
    What's in itFrom Claude Haiku if you add a key, or Apple Vision on-device if you don't.
    1

    Only AirDrops

    It watches the top of ~/Downloads and only touches files macOS marked as delivered by AirDrop. Browser downloads are left alone.

    2

    HEIC becomes JPEG

    Photos are converted so they open anywhere. Screenshots and JPEGs are just renamed. Live Photo videos get the same name as their photo.

    3

    Undo anything

    Originals go to the Trash, never deleted, and every change is journaled. airname undo puts the last batch back exactly as it was.

    Privacy

    Your coordinates never leave the Mac.

    Pick the engine. If Claude fails for any reason (no network, a timeout, a refusal), Vision names the photo instead, so a rename never fails.

    Apple Vision On-device

    • Sends nothing anywhere.
    • Always runs: it reads text and spots receipts, documents and screenshots.
    • Honest but flat names that read like tags.

    Claude Haiku 4.5 Your API key

    • Sends a 1024 px JPEG with all metadata removed: no EXIF, no GPS.
    • Plus a little text: the date, the city name, the kind and a short OCR snippet.
    • Anthropic doesn't train on API inputs. Turn it off with one line of config.
    Install

    Try it today, from source.

    BetterAirDrop is pre-alpha; the command-line tool it installs is called airname. A menu-bar app with a one-line installer is next; for now it runs in a Terminal window. Needs macOS 13+ and Swift 6 (Xcode 16 or the command line tools).

    $ git clone https://github.com/MoizAhmedd/betterairdrop.git && cd betterairdrop $ swift build -c release $ .build/release/airname watch --foreground # now AirDrop something to this Mac
    rename --dry-runSee what it would do to files you already have.
    explain <file>Show the context and why it picked a name.
    undoPut the last batch back.
    auth claudeStore an API key in your Keychain.
